# راهنمای فارسی — کار ۷: فارغ‌التحصیلی و بستن پرونده (M10)

## درخواست فارغ‌التحصیلی
- ثبت‌کننده: مالک پرونده. پیش از ثبت، `canApproveFinal` (همان Rule Engine) بررسی می‌شود؛
  نقص‌ها به‌صورت **فهرست دلایل فارسی** برگردانده و در UI نشان داده می‌شوند (`409` + دلیل).
- درخواست تکراری در حالت «در انتظار» ⇒ `409 REQUEST_PENDING`.

## تصمیم
- دارندهٔ `cases.archive` یا `cases.review_topic`: تأیید یا رد.
- **رد بدون دلیل ممکن نیست** (حداقل ۵ نویسه).
- تأیید، مجدداً شرط‌های نهایی را کنترل می‌کند؛ اگر شرطی از بین رفته باشد، تصمیم رد می‌شود و دلیل
  دقیقاً ذکر می‌شود (بدون تصمیم نیمه‌کامل).

## بستن پرونده
- دارندهٔ `cases.archive` با **دلیل إلزامی**: `closeCase`.
- `archived_at` ثبت و شکل نهایی `rule_snapshot` (وضعیت قوانین در لحظهٔ بستن) در رکورد
  `case_closures` نگه‌داری می‌شود تا بعدها قابل بازخوانی باشد.
- پروندهٔ بسته‌شده ⇒ `409 ALREADY_CLOSED`؛ پروندهٔ بسته در همهٔ صف‌ها و شمارنده‌ها از کار می‌افتد.
- رکورد فارغ‌التحصیلی و بستن **هرگز حذف نمی‌شوند**.

## گاردها
| شرط | پاسخ |
| --- | --- |
| درخواست با نقص شرط‌ها | `409` + فهرست دلایل فارسی |
| درخواست تکراری در انتظار | `409 REQUEST_PENDING` |
| رد بدون دلیل | `400 REASON_REQUIRED` |
| بستن بدون دلیل | `400 REASON_REQUIRED` |
| بستن پروندهٔ بسته | `409 ALREADY_CLOSED` |
