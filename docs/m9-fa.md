# راهنمای فارسی — کار ۶: جلسهٔ دفاع (M9)

## پیش‌نیاز قطعی
درخواست دفاع فقط زمانی پذیرفته می‌شود که **موتور قوانین** اجازه بدهد؛ Rule Engine یکی از دو پاسخ
`ALLOW` یا `DENY` + **دلیل دقیق فارسی** می‌دهد (بدون هیچ آستانهٔ سخت‌کدشده). دلایل ممکن:
- پروپوزال مصوب نشده
- ایرانداک تأیید نشده
- نسخهٔ پایان‌نامه تأییدشدهٔ فعال وجود ندارد
- همانندجویی قبول نشده
- بدهی مالی تسویه‌شده نیست (اگر مالی برای پرونده لازم باشد)

## تشکیل جلسه
- تشکیل‌کننده: دارندهٔ `cases.review_topic` (تحصیلات تکمیلی).
- فرم: نوع جلسه (`pre_defense` / `final_defense`)، تاریخ شمسی، ساعت، محل، اعضای کمیته.
- اگر Rule Engine اجازه ندهد ⇒ `409 RULE_DENIED` با همان دلایل فارسی؛ **دکمهٔ UI هم پیش از
  کلیک همان دلایل را نشان می‌دهد** و غیرفعالِ بی‌توضیح نیست.
- برای دفاع نهایی، حد نصاب اعضا بررسی و در نبود آن با دلیل فارسی رد می‌شود.

## ثبت نتیجه
- نتیجه (`held` / `cancelled`) + صورت‌جلسه (فایل) + یادداشت.
- دفاع نهایی برگزارشده ⇒ گردش کار `DEFENSE_COMPLETED`؛ در غیر آن ⇒ `DEFENSE_REVISION`
  با الزام دلیل.
- تغییر نتیجه پس از ثبت ممکن نیست؛ رکوردهای قبلی در تاریخچه می‌مانند.

## گاردها
| شرط | پاسخ |
| --- | --- |
| درخواست دفاع بدون شرط‌های قوانین | `409 RULE_DENIED` + دلایل فارسی |
| حد نصاب ناکافی (دفاع نهایی) | `400 QUORUM_NOT_MET` + تعداد اعضای لازم |
| ثبت نتیجه توسط غیرمجاز | `403 FORBIDDEN` |
| نتیجهٔ تکراری برای یک جلسه | `409 ALREADY_DECIDED` |
